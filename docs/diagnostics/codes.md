# :material-code-tags: Diagnostic Codes

All diagnostic codes are **stable** — they will not change across versions. Use them in tooling and automation.

---

## :material-file-code: YAML Parsing Errors

These codes are generated by `HardenedYamlParser` and are always **blocking**.

| Code | Severity | Description |
|------|----------|-------------|
| `YAML_INVALID_UTF8` | error | File is not valid UTF-8 |
| `YAML_SYNTAX_ERROR` | error | File is not parseable YAML |
| `YAML_MULTIPLE_DOCUMENTS` | error | File contains more than one YAML document |
| `YAML_ROOT_NOT_MAPPING` | error | Root YAML node is not a mapping (object) |
| `YAML_ALIAS_UNSUPPORTED` | error | YAML anchor/alias detected |
| `YAML_NON_STRING_KEY` | error | A mapping key is not a string |
| `YAML_DUPLICATE_KEY` | error | A mapping has duplicate keys |
| `YAML_TAG_UNSUPPORTED` | error | An unsupported YAML tag was used |
| `YAML_TIMESTAMP_UNSUPPORTED` | error | A date/timestamp value must be quoted |
| `YAML_NON_FINITE_NUMBER` | error | NaN or Infinity floating-point value |

## :material-star: VSF IDP v2 Schema Errors

These codes are generated for `specVersion: vsf-idp.io/v2` descriptors.

| Code | Severity | Blocking | Description |
|------|----------|----------|-------------|
| `SCHEMA_SPEC_VERSION_INVALID` | error | ✅ | `specVersion` is not `"vsf-idp.io/v2"` |
| `SCHEMA_METADATA_REQUIRED` | error | ✅ | `metadata` missing or not an object |
| `SCHEMA_SPEC_INVALID` | error | ✅ | `spec` missing or not an object |
| `SCHEMA_FIELD_REQUIRED` | error | ✅ | A required field is absent or blank |
| `SCHEMA_FIELD_INVALID` | error | ✅ | A field fails pattern/type validation |

## :material-history: Backstage Schema Errors

These codes are generated for Backstage-format descriptors.

| Code | Severity | Blocking | Description |
|------|----------|----------|-------------|
| `SCHEMA_API_VERSION_REQUIRED` | error | ✅ | `apiVersion` is missing or not a string |
| `SCHEMA_KIND_REQUIRED` | error | ✅ | `kind` is missing or not a string |
| `SCHEMA_METADATA_REQUIRED` | error | ✅ | `metadata` missing or not an object |
| `SCHEMA_METADATA_NAME_REQUIRED` | error | ✅ | `metadata.name` is missing |
| `SCHEMA_SPEC_INVALID` | error | ✅ | `spec` is present but not an object |

## :material-relation-many-to-many: Relation and Topology Errors

These codes are generated by `BackstageRelationProjector`.

| Code | Severity | Blocking | Description |
|------|----------|----------|-------------|
| `REFERENCE_INVALID` | error | ✅ | A reference field is not a valid entity reference string |
| `REFERENCE_TARGET_NOT_FOUND` | warning | ❌ | Referenced entity is not in the catalog |
| `TOPOLOGY_SELF_REFERENCE` | error | ✅ | Entity declares a relation to itself |

---

## :material-content-copy: Identity Conflicts

Generated by `CatalogWorkspace` when two files claim the same canonical reference.

| Code | Severity | Blocking | Description |
|------|----------|----------|-------------|
| `ENTITY_DUPLICATE_REF` | error | ✅ | Two or more files declare the same entity reference |

**Resolution:** Change `metadata.namespace` or `spec.id` (VSF) / `metadata.name` (Backstage) in one of the conflicting files.
